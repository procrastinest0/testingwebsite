# Kaushal's Corner ✏️

A hand-drawn, pastel, interactive personal website. Plain HTML/CSS/JS — no build step.

## Edit your content
Look for `✏️ EDIT` comments in:
- `index.html` — intro, sticky notes, cards, purpose list, contact links
- `script.js` — the rotating "I'm a ..." words and the random facts

## Host on GitHub Pages
1. Merge this into your default branch (e.g. `main`).
2. Repo → **Settings → Pages** → Source: *Deploy from a branch* → `main` / `(root)`.
3. Your site appears at `https://procrastinest0.github.io/testingwebsite/`.
